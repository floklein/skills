# Publishing and Measurement

Read this file only when the user asks about distribution, timing, follow-through, or performance.

## Timing

- Publish while the target audience is likely awake and able to engage.
- Treat universal best-time studies as hypotheses. Prefer the account's own audience and performance data.
- Verify current platform rules and any current timing claim before presenting them as facts.

## Follow-through

- Reply thoughtfully while the conversation is active.
- Rework a strong idea later through a different pattern, example, or visual.
- Test visuals when they demonstrate the point more clearly than prose.

## Measurement

Evaluate the post against its purpose. Track useful downstream signals such as bookmarks, profile visits, follows, qualified replies, and conversions alongside likes and reposts. Compare like with like across multiple posts before drawing a conclusion.
