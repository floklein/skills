# Tweet Patterns

Read this file when the post needs a structure, the draft feels flat, or the user requests variants. Choose the smallest pattern that can carry the claim. For variants, change the rhetorical angle rather than merely paraphrasing the same sentences.

## Compressed insight

Use for a familiar subject with a useful reframe.

1. State the common observation.
2. Reframe what it actually means.
3. Land on why the distinction matters.

## Contrarian claim

Use when the writer genuinely disagrees with a recognizable consensus.

1. Name the accepted belief.
2. State the disagreement immediately.
3. Support it with a defensible reason or example.

Choose a position the writer can defend and prioritize audience trust over empty impressions.

## Specific result

Use when a real change produced a measurable outcome.

1. State what changed.
2. Give the before and after result.
3. Reveal the mechanism or surprising lesson.

Use only supplied or verified numbers.

## Before / after

Use when a product, workflow, sentence, or decision became visibly simpler.

1. Show the old state.
2. Show the new state.
3. Name the broader principle the contrast reveals.

## Honest lesson

Use when a mistake, failed assumption, or tradeoff produced a useful insight.

1. Name the concrete action or mistake.
2. State the cost or consequence.
3. End with the earned lesson.

Keep the vulnerability proportional to the evidence. Ground honesty in specific details.

## Useful list

Use when several parallel signals or rules are individually memorable.

1. Open with the benefit or diagnostic question.
2. Include only the strongest items, usually three.
3. Make each item concrete and independently useful.

## Visual demonstration

Use when motion, appearance, timing, or comparison is the proof.

1. Name what the viewer should notice.
2. Add the concrete constraint, iteration, or difference.
3. Let the attached media deliver the evidence.

## Developer-account default

Use this reliable form when no other pattern clearly wins:

1. Unexpected claim
2. Concrete observation or evidence
3. Broader lesson

Model choice, implementation detail, or product news is rarely the whole idea. Lead with the insight another practitioner would want their followers to see.
